# EditAnt

Safe, section-addressed editing of structured documents, Markdown first, so a person or an LLM can replace one named
section of a document without any risk of corrupting or erasing anything outside it.

**Status: design only. Nothing here is usable yet.** The crate name `editant` is reserved on crates.io at 0.0.0.
